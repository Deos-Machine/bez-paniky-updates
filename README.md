# без паніки.

Графіки відключень світла: відлік до вимкнення й увімкнення, попередження заздалегідь, віджети. Працює без інтернету.

## Встановити

1. Відкрий [останній реліз](https://github.com/Deos-Machine/bez-paniky-updates/releases/latest) з телефона.
2. Завантаж файл **`bez-paniky-…-arm64.apk`**. Якщо не встановлюється — **`bez-paniky-…-universal.apk`**.
3. Відкрий файл і натисни «Встановити». Телефон попросить дозволити встановлення з браузера — дозволь.

Далі застосунок сам підкаже, коли вийде нова версія.

## Приватність

Адреси зберігаються лише на телефоні. Без реклами, акаунтів і стеження.

Перевірити, що файл справжній: SHA-256 кожного APK вказаний в описі релізу.
